# Agent Autopsy

Collection of prompts and tool schemas for coding agents.

- `codex/`: prompts and tool schemas from the Codex source tree.
- `claude-code/`: Claude Code non-interactive captures, plus `interactive/` tmux captures.
- `antigravity/`: Antigravity CLI non-interactive captures, plus `interactive/` tmux captures.
- `ampcode/`: Amp prompts and mode-specific tool schemas.
